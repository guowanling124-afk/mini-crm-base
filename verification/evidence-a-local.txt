notes for the report
------------------------------------------------------------------------
* A1: the canonical README payload leaves NO visible trace in the log
  itself -- the line just reads 'Processing issue: '. The only
  evidence is the artefact on the (ephemeral) runner. Use A1 as the
  reproduction recipe, but capture A2-style output for the write-up.
* A2: execution happens because the expression is expanded into the
  script text BEFORE bash parses it. The fixture already wraps the
  line in double quotes, and that does not help -- quoting is applied
  after expansion, not before.
* A3: in an unquoted context a newline in the title starts a new
  command even without $(). This is why 'just remove $()' is not a
  fix either.
* A4: the actual fix is to stop the value being script at all -- pass
  it through env and reference "$TITLE" (bot.yml does exactly this).
* Scope: this job declares `permissions: contents: read` and holds no
  secrets, so the impact is runner-local code execution, not
  credential theft. Do not overstate it in the report.
